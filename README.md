# 挑战点系统 v0.1.2

《杀戮尖塔 2》的开局挑战契约。选角界面右上角打开「挑战点契约」，点大号 `＋` / `－` 选择词条等级。通用挑战点与当前角色挑战点**分开计算**；达到阈值后累计领奖，不扣除点数。选择自动保存，开局时快照锁定，重新打开游戏也会保留预设。

## 内容

- 25 个通用挑战词条；战士、储君、亡灵契约师、猎手、故障机器人各 8 个专属词条，共 65 个可选词条。完整数值在 `ChallengePointsData.json` 中。
- 通用奖励：15 护喉甲、20 小型扭蛋、35 龙涎香、55 每场战斗 5 层金属化、70 升级所有初始牌、90 第一个商店的卡牌、药水及一次删牌免费；三个遗物仍需付费。
- 角色奖励：10 点首回合自动打出指定能力牌；20 点替换一张打击与一张防御；35 点从本角色完整卡池选择并打出一张升级牌；42 点从扩展卡池再选一张不同名升级牌。除灵动步伐外，奖励牌均升级。
- 不包含此前取消的 50 点「贴贴」奖励。
- 界面与状态图标为专门生成的手绘厚涂资源：大色块、宽描边、暖色羊皮纸、深色木框；触控按钮随屏幕缩放。

## 版本与依赖

| 包名后缀 | 对应游戏 | 验证情况 |
|---|---|---|
| 电脑-v107.1 | PC Steam v0.107.1 | 本次编译、离线流程回归通过；本次未运行游戏界面 |
| 手机-v110.1 | Android v0.110.1 | 本次编译、离线流程回归通过；ADB 无设备，未实机验证 |

不需要 BaseLib。故障机器人 35 点卡池中的「散热片」由 **BetterDefect** 提供；不装 BetterDefect 时，该一张候选牌不会出现，其余角色和词条仍可使用。

PC v107.1 尚无官方「龙涎香」，电脑版内置了等效的兼容药水：回复最大生命值的 50%，若在战斗中使用，则获得一个额外回合。手机版 v110.1 使用游戏自带的龙涎香。

## v0.1.2 开局黑屏修复

- 交互式开局奖励改为在房间黑幕淡出完成后发放。旧版在 `AfterRoomEntered` 中等待小型扭蛋的领奖窗口关闭，而房间黑幕要等该钩子返回才淡出，造成互相等待；非战斗动作执行器当时也尚未恢复。
- 保留涅奥的正常祝福选项，不改为自动跳过涅奥，不减少挑战奖励。
- 开局奖励只发放一次，并阻止领奖期间嵌套淡入导致重复发奖。添加房间进入、淡入完成、小型扭蛋领奖开始/结束的诊断日志。
- `RunManager.FadeIn` 在 PC v107.1 为私有方法，在手机 v110.1 为公开方法；本次使用统一的 Harmony 方法名定位。

**本次验证范围：**手机 v110.1、PC v107.1 各自编译通过（0 警告/0 错误）；使用两份实际 DLL 检查“淡入前不发奖、淡入后才打开交互奖励、等奖励结束、淡入失败/取消不发奖”，并反射检查目标接口。另有源码回归检查。以上不是游戏内实机测试。

用户日志记录的实际游戏是 **v0.111.0**。本机没有该版本程序集，也没有 ADB 设备，故本次手机包仍标注 **v110.1 构建**，不冒充 v111 专门编译或已验证兼容。日志能确认 v0.1.1 已加载且涅奥选项恢复代码执行；没有明确记录所有异步任务的等待链，本次修复针对源码中确认存在的黑屏互等路径。

请覆盖同一个 `ChallengePoints` 文件夹，不要并存旧 DLL；先使用新开的一局验证涅奥和挑战奖励。更新不删除预设或存档；旧版已经置为“奖励发放完成”的存档不会自动重新发奖，避免重复遗物。

## 安装

压缩包内有 `ChallengePoints` 文件夹。将该文件夹完整解压到游戏的 `mods` 目录，最终应是 `mods/ChallengePoints/ChallengePoints.dll` 与 `mods/ChallengePoints/ChallengePoints.json`。手机版需使用支持 DLL MOD 的启动器，并将**手机-v110.1** 包放入该启动器使用的 `mods` 目录。不要把电脑版 DLL 装到手机版。

发布包不会自动安装，也不会修改现有一键安装器。

## 重要实现约定

设计文档中未定的细节，本版固定为：IC-03 每消耗 2 张牌加 1 张伤口，IC-05 受到易伤时额外加 1 层；RG-05 每回合最多生成 5 张无色牌；DF-02 闪电/冰霜球数值上限 33；DF-06 黑暗球上限 33、等离子球数值 -1。相邻火堆指连续楼层的两个火堆。第 1 个商店免费规则包括一次删牌服务，但不包括遗物。

## 构建

需要 .NET 9、Godot.NET.Sdk 4.5.1、目标版本 `sts2.dll` 与 `0Harmony.dll`。PC：

```powershell
dotnet build ChallengePoints.csproj -c Release -p:Sts2DataDir="<游戏目录>/data_sts2_windows_x86_64"
```

Android v110.1：

```powershell
dotnet build ChallengePoints.csproj -c Release -p:Sts2DataDir="<Android v110.1 程序集目录>" -p:Sts2TargetFlavor=mobile-v110
```
