# 挑战点系统 v0.2.3

《杀戮尖塔 2》开局契约与分队商店 MOD。选角界面点「挑战点契约」，先选挑战赚点，再到「分队商店」购买分队和小商品。通用点与当前角色点**合并支付**，但仍分别显示；配置自动保存，开局后锁定。无需 BaseLib。

## v0.2.3 修正

- 「攻防一体」二级开局升级**所有铁斩波**，保留防御牌；三级改为获得**水果刀遗物**，其火堆选项删除恰好 1 张牌并增加 6 点最大生命；四级每击杀 1 名非爪牙敌人仅升级随机 1 张铁斩波。旧版错误发放的切肉刀卡会在安全场景迁移为水果刀遗物；已经被错误替换的防御牌无法凭空还原，二级开局牌组更正请开启新局。
- 「钻石胸甲」改为每回合结束获得 **5 点格挡**。
- 开战已有敌人也获得挑战增益；之后召唤的敌人继续通过原有召唤钩子获得增益。G-12 金属化按词条等级给 3／6／9 层，上限三级，不再按楼层计算。
- PC v0.107.1 隔离环境通过模型/存档、遗物火堆、初始敌人增益、回合末格挡、铁斩波击杀升级实战测试。手机 v0.111.0 仅编译，未安装或实测。

## 本版内容

- 保留 25 个通用、每角色 8 个专属挑战词条；原有自动阈值奖励仅对旧存档保留，新局改为购买制。
- 10 支分队，各有 4 级，总价而非逐级叠加。可同时买多支；随机分队跨角色抽选，与直接购买同一支时取较高等级、不重复叠加。
- 9 件小商品，每局配置中各限买 1 次。商店折扣、卡牌选择、删牌/转化、保命等效果随本局契约保存。
- 新增光明券、生成灵体、灵体印刷机；水果刀是遗物而非卡牌。旧切肉刀卡牌类型只为旧存档迁移保留，不再发放，也不进入普通卡牌奖励池。
- 局内左侧「契约」标记可查看已购分队、商品及负面挑战计数；它不是实际遗物，不占遗物位，也不触发获得遗物事件。
- 通用原 1 点/级的六项挑战改为 2 点/级；战士奇偶回合失去力量只在当前力量至少为 1 时触发；机器人状态牌词条改为回合开始将弃牌堆一张状态牌放到抽牌堆。
- 修复先前重复注入自定义卡牌模型的启动问题，并保留捏奥祝福兼容逻辑。旧局以旧规则继续，新局使用新商店。

详细数值、购买顺序和未说明处的原定稿见 `design/挑战点系统_分队商店更新规划_v0.6.docx`；本版更正以 `design/v0.2.3-勘误.md` 为准。

## 安装

将压缩包中的 `ChallengePoints` 目录完整放进游戏或启动器的 `mods` 目录，使路径为 `mods/ChallengePoints/ChallengePoints.dll` 和 `mods/ChallengePoints/ChallengePoints.json`。**电脑版 DLL 与手机版 DLL 不可互换。** 本次只交付压缩包，不修改手机现有 MOD，也不更新一键安装器。

## 构建

需要 .NET 9、Godot.NET.Sdk 4.5.1、目标版本的 `sts2.dll` 与 `0Harmony.dll`。

```powershell
dotnet build ChallengePoints.csproj -c Release -p:Sts2DataDir="<PC游戏目录>/data_sts2_windows_x86_64"
dotnet build ChallengePoints.csproj -c Release -p:Sts2DataDir="<Android v0.111.0 程序集目录>" -p:Sts2TargetFlavor=mobile-v110
```

界面底图和既有图标为此 MOD 原创生成；新增卡牌复用游戏内现有卡图，并非外部资源。无 BaseLib、RitsuLib 依赖。
