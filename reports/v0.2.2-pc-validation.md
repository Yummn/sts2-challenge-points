# v0.2.2 PC 验证记录

环境：Steam 版游戏 v0.107.1 的隔离副本，仅加载挑战点系统；使用 `CHALLENGE_POINTS_SMOKE=1` 与 `CHALLENGE_POINTS_INTEGRATION` 测试入口。手机版 v0.111.0 只完成编译，未安装或实机测试。

| 项目 | 结果 | 证据 |
|---|---|---|
| 编译、模型注册、独立点数、存档往返 | 通过 | SmokeRunner，进程退出码 0 |
| 捏奥开局与契约标记 | 通过 | PC 新局集成测试 |
| IT-03 能力三选一 | 通过 | `choice` 集成测试，界面等待玩家选择 |
| SQ-07 切肉刀伤害与格挡 | 通过 | `battle` 真实战斗，出牌后敌方失血、我方获得格挡 |
| SQ-07 四级铁斩波击杀升级 | 通过 | 连续升级至三级，卡牌序列化/反序列化后等级保持；真实战斗击杀升至二级并保存 |
| SQ-02 光明券 | 通过 | `light` 真实战斗，生成牌绑定玩家并成功打出 |
| SQ-03 灵魂／鬼火 | 通过 | `soul` 真实战斗，回合开始生成两类牌且持有者正确 |
| SQ-05 状态牌奖励 | 通过 | `status` 真实战斗，产生状态牌后生成燃料 |
| SQ-09 生成灵体 | 通过 | `spirit` 真实战斗，技能打出后灵体进入抽牌堆且持有者正确 |
| 捏奥流程与游戏接口回归测试 | 通过 | `verify_challenge_points_neow.py`、`ChallengeStartupFlowTests` |

此次测试发现并修复了原版发布包中两类缺陷：铁斩波超出通常升级上限时的异常、分队生成牌缺少 `Owner` 时的异常。以上仅覆盖表中案例，不等于全部挑战词条和四级分队均已逐项通关。隔离副本从 Steam 外启动时偶发 Steam 初始化失败；失败启动不会当作模组通过或失败，重新启动后再执行测试。
