# 分队商店 v0.2.3 勘误

本文件覆盖 v0.6 规划文档中与以下项目相抵触的描述，依据用户实测反馈。

| 项目 | 更正后的规则 |
|---|---|
| 攻防一体 II | 开局升级牌组中的所有铁斩波；不替换防御牌。 |
| 攻防一体 III | 开局获得水果刀**遗物**。火堆可选删除 1 张可移除卡牌，并获得 6 点最大生命；不是切肉刀卡牌。 |
| 攻防一体 IV | 击杀非爪牙敌人时随机升级牌组中的**一张**铁斩波；该张牌可重复升级。 |
| 钻石胸甲 | 每回合结束获得 5 点格挡。 |
| G-12 金属化 | 词条一级／二级／三级分别使敌人获得 3／6／9 层金属化；与楼层无关。 |
| 敌人增益 | 战斗开场已有的敌人和战斗中召唤的敌人均获得所选挑战增益。 |

旧存档中错误发放的切肉刀卡将在进入安全场景时迁移为水果刀遗物。旧存档中已替换的防御牌不能可靠推断原始构成；二级开局卡组修复仅适用于新局。
